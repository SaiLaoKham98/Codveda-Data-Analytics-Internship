# Codveda Data Analytics Internship Projects

This repository contains the projects and tasks I completed as part of my **Data Analytics Internship at Codveda Technologies**.

The projects cover exploratory data analysis, data visualization, regression, clustering, classification, model evaluation, and business intelligence dashboard development using Python and Power BI.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Power BI

### Level 1 — Exploratory Data Analysis & Visualization

#### Task 2: Iris Exploratory Data Analysis

**File:** `Level1_Task2_Iris_EDA.ipynb`

Performed exploratory data analysis on the Iris dataset to understand its structure, distributions, and relationships between features.

**Skills demonstrated:**
- Data inspection

- Exploratory Data Analysis (EDA)
- Data visualization
- Pandas

**File:** `Level1_Task3_Stock_Data_Visualization.ipynb`

**Skills demonstrated:**
